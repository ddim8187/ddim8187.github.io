대출 추가

매달 출금일이 지나면 캘린더에 예상 상환액이 자동으로 표시돼요. 실제 금액이 다르면 캘린더에서 해당 날짜를 눌러 직접 수정할 수 있어요.

이 가계부는 이렇게 작동해요

  • 모든 기록은 회원가입이나 로그인 없이, 이 브라우저의 저장공간(localStorage)에만 남습니다.
  • 다른 휴대폰·PC나 다른 브라우저에서는 같은 기록이 보이지 않습니다. 기기를 바꾸거나 여러 기기에서 같이 쓰려면 내보내기로 백업한 파일을 다른 기기에서 불러오면 됩니다.
  • 브라우저 기록(사이트 데이터)을 지우거나 시크릿 모드로 열면 기록이 사라집니다. 주기적인 백업을 권장합니다.
  • 부부가 같이 쓰는 동기화 기능은 없습니다. 함께 쓰려면 한 대의 기기를 둘이 같이 쓰거나, 백업 파일을 서로 주고받아 수동으로 맞춰야 합니다.

내보내기·불러오기 사용법

백업(내보내기)

상단 오른쪽의 내보내기 버튼을 누르면 지출·수입, 대출, 한도 등 모든 데이터가 하나의 JSON 파일로 다운로드됩니다. 이 파일을 클라우드 저장소나 메일로 보관해두면 기기가 바뀌거나 고장나더라도 데이터를 지킬 수 있습니다.

복원(불러오기)

불러오기를 누르고 백업해둔 JSON 파일을 선택하면 됩니다. 불러오기를 하면 현재 기기에 있던 기록은 모두 데이터 파일의 내용으로 교체됩니다. 기존 기록과 합치는 기능은 아니므로, 필요하면 미리 내보내기로 현재 기록을 따로 저장해두세요.

자주 묻는 질문

앱을 삭제하거나 브라우저 데이터를 지우면 기록도 사라지나요?

네. 데이터가 이 브라우저에만 저장되므로, 사이트 데이터를 지우거나 시크릿/개인정보 보호 모드로 사용하면 기록이 사라집니다. 중요한 기록은 미리 내보내기로 백업해주세요.

여러 기기에서 동시에 쓸 수 있나요?

실시간으로 동기화되지는 않습니다. 한 기기에서 입력한 뒤 내보내기로 파일을 만들고, 다른 기기에서 불러오기로 그 파일을 열어야 같은 내용을 볼 수 있습니다. 부부가 함께, 수시로 쓰려면 로그인을 지원하는 별도 공유형 버전을 이용하셔야 합니다.

대출 상환액은 어떻게 계산되나요?

원리금균등상환과 원금균등상환 두 방식을 지원합니다. 대출 시작일의 '일'을 기준으로 매달 출금일을 계산하며, 해당 월에 그 날짜가 없으면 말일로 보정합니다. 철저히 계산기 용도이므로, 실제 출금액은 은행에서 받은 안내를 기준으로 해주세요.
