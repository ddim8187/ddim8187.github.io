바코드 종류와 차이 (Code 128, EAN-13, QR코드)

최종 수정일 2026-10-01

바코드는 용도에 따라 종류가 다릅니다. 매장 판매용 상품 바코드는 따로 발급받아야 하고, 사내 재고·물류 라벨은 Code 128로 직접 만들어 쓸 수 있습니다.

목차
  1. 대표적인 세 가지 비교
  2. 판매용 상품 바코드는 직접 만들면 안 돼요
  3. Code 128은 언제 쓰나요
  4. 인쇄해서 쓸 때 팁

대표적인 세 가지 비교

종류담을 수 있는 내용주로 쓰는 곳
EAN-13숫자 13자리마트·편의점 판매 상품
Code 128영문, 숫자, 기호물류 송장, 재고·자산 관리 라벨
QR코드URL, 문장, 와이파이 정보 등 수천 자홍보물, 결제, 링크 공유

판매용 상품 바코드는 직접 만들면 안 돼요

마트나 온라인몰에 입점하는 상품의 바코드(EAN-13)는 숫자를 아무렇게나 정해서 만들면 안 됩니다. 국내에서는 GS1 Korea에 회원으로 가입해 국가코드 880으로 시작하는 고유 번호를 발급받아야, 다른 상품과 번호가 겹치지 않고 유통업체 시스템에서 정상적으로 인식됩니다.

바코드 생성기는 이렇게 발급받은 번호를 이미지로 그려주는 역할일 뿐이며, 번호 자체를 만들어주지는 않습니다.

Code 128은 언제 쓰나요

Code 128은 영문·숫자·기호를 모두 담을 수 있고 길이도 자유로워서, 회사 안에서 정해 쓰는 코드에 잘 맞습니다.

  • 창고 로케이션 라벨(예: A-01-03)
  • 재고 관리번호, 자산 관리 태그
  • 출고 박스·택배 송장 번호

숫자로만 된 짝수 자리 코드는 Code 128 안에서도 숫자 전용 방식(C)으로 압축돼 바코드 폭이 더 좁아집니다.

인쇄해서 쓸 때 팁

  • 바코드 양옆에 여백(조용한 구역)을 충분히 남겨야 스캐너가 잘 읽습니다.
  • 막대 폭(모듈 폭)이 너무 좁으면 저가형 프린터에서 번져 인식이 안 될 수 있습니다.
  • 인쇄용이라면 확대해도 깨지지 않는 SVG로 내려받는 것을 추천합니다.
이 글과 함께 보면 좋은 도구
  • QR 코드·바코드 생성기
이 글은 일반적인 정보 제공을 목적으로 하며, 개인의 상황에 따라 결과가 달라질 수 있습니다. 중요한 결정은 관련 기관의 공식 안내나 전문가 상담을 통해 확인해 주시기 바랍니다.
